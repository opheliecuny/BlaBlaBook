# Dictionnaire de données

Le dictionnaire de données décrit de manière exhaustive toutes les tables de la base de données, leurs champs, types, contraintes et relations.

---

## Table : `user`

**Description** : Stocke les informations des utilisateurs inscrits sur la plateforme.

| Champ     | Type                     | Contraintes               | Description                                         |
| --------- | ------------------------ | ------------------------- | --------------------------------------------------- |
| id        | UUID                     | PRIMARY KEY, DEFAULT uuid | Identifiant unique de l'utilisateur                 |
| email     | VARCHAR(255)             | UNIQUE, NOT NULL          | Adresse email utilisée pour la connexion            |
| password  | VARCHAR(255)             | NOT NULL                  | Mot de passe haché avec argon2                      |
| username  | VARCHAR(100)             | NOT NULL                  | Nom d'utilisateur affiché publiquement              |
| createdAt | TIMESTAMP WITH TIME ZONE | DEFAULT CURRENT_TIMESTAMP | Date et heure de création du compte                 |
| updatedAt | TIMESTAMP WITH TIME ZONE | DEFAULT CURRENT_TIMESTAMP | Date et heure de la dernière modification du profil |

**Relations** :

- Un utilisateur peut avoir plusieurs entrées dans `library_item` (relation 1:N)

---

## Table : `book`

**Description** : Catalogue des livres issus de l'API Open Library Books.

| Champ         | Type         | Contraintes               | Description                                                 |
| ------------- | ------------ | ------------------------- | ----------------------------------------------------------- |
| id            | UUID         | PRIMARY KEY, DEFAULT uuid | Identifiant unique interne du livre                         |
| isbn          | VARCHAR(20)  | -                         | Numéro ISBN du livre (optionnel)                            |
| openLibraryId | VARCHAR(100) | UNIQUE                    | Identifiant provenant de l'API Open Library (ex: OL123456W) |
| title         | VARCHAR(255) | NOT NULL                  | Titre du livre                                              |
| author        | VARCHAR(255) | -                         | Nom de l'auteur ou des auteurs                              |
| genre         | VARCHAR(100) | -                         | Genre littéraire (Fiction, Science-fiction, Histoire, etc.) |
| description   | TEXT         | -                         | Résumé ou description complète du livre                     |
| thumbnail     | VARCHAR(512) | -                         | URL de l'image de couverture                                |
| publisher     | VARCHAR(255) | -                         | Nom de l'éditeur                                            |
| pageCount     | INTEGER      | -                         | Nombre de pages du livre (optionnel)                        |
| language      | VARCHAR(10)  | -                         | Langue du livre (code ISO 639-1 : fr, en, es, etc.)         |
| publishedYear | INTEGER      | -                         | Année de publication                                        |

**Relations** :

- Un livre peut apparaître dans plusieurs bibliothèques via `library_item` (relation N:N via table de liaison)

---

## Table : `library_item`

**Description** : Table de liaison entre les utilisateurs et les livres, représentant la bibliothèque personnelle de chaque utilisateur.

| Champ     | Type                     | Contraintes                      | Description                                                    |
| --------- | ------------------------ | -------------------------------- | -------------------------------------------------------------- |
| id        | UUID                     | PRIMARY KEY, DEFAULT uuid        | Identifiant unique de l'entrée dans la bibliothèque            |
| userId    | UUID                     | NOT NULL, FOREIGN KEY → user(id) | Référence à l'utilisateur propriétaire                         |
| bookId    | UUID                     | NOT NULL, FOREIGN KEY → book(id) | Référence au livre concerné                                    |
| status    | ReadingStatus (ENUM)     | NOT NULL, DEFAULT 'TO_READ'      | Statut de lecture : TO_READ, READING, READ                     |
| rating    | INTEGER                  | CHECK (rating BETWEEN 1 AND 5)   | Note attribuée par l'utilisateur (1 à 5 étoiles, optionnel)    |
| review    | TEXT                     | -                                | Commentaire ou avis personnel sur le livre (optionnel)         |
| createdAt | TIMESTAMP WITH TIME ZONE | DEFAULT CURRENT_TIMESTAMP        | Date et heure d'ajout du livre à la bibliothèque               |
| updatedAt | TIMESTAMP WITH TIME ZONE | DEFAULT CURRENT_TIMESTAMP        | Date et heure de la dernière modification (statut, note, avis) |

**Contraintes** :

- `UNIQUE (userId, bookId)` : Un utilisateur ne peut ajouter le même livre qu'une seule fois
- `ON DELETE CASCADE` : Si un utilisateur ou un livre est supprimé, les entrées correspondantes sont automatiquement supprimées

**Relations** :

- Appartient à un utilisateur (`userId` → `user.id`)
- Référence un livre (`bookId` → `book.id`)

---

## Type ENUM : `ReadingStatus`

**Description** : Enumération représentant les différents statuts de lecture possibles.

| Valeur    | Signification       | Description                                    |
| --------- | ------------------- | ---------------------------------------------- |
| `TO_READ` | A lire              | Le livre est dans la liste des livres à lire   |
| `READING` | En cours de lecture | L'utilisateur est en train de lire ce livre    |
| `READ`    | Lu / Terminé        | L'utilisateur a terminé la lecture de ce livre |

## Index et Performances

### Index recommandés

**Table `user`** :

- Index sur `email` (automatique via UNIQUE)

**Table `book`** :

- Index sur `openLibraryId` (automatique via UNIQUE)
- Index optionnel sur `title` pour améliorer les recherches

**Table `library_item`** :

- Index composite sur `(userId, bookId)` (automatique via UNIQUE)
- Index sur `userId` (automatique via FOREIGN KEY)
- Index sur `bookId` (automatique via FOREIGN KEY)
- Index optionnel sur `status` pour filtrer par statut de lecture

## Règles de gestion

1. **Unicité des utilisateurs** : Un email ne peut être associé qu'à un seul compte.
2. **Unicité des livres** : Un livre (identifié par `openLibraryId`) n'est présent qu'une seule fois dans la table `book`.
3. **Bibliothèque personnelle** : Un utilisateur ne peut ajouter le même livre qu'une seule fois à sa bibliothèque.
4. **Cascade de suppression** : La suppression d'un utilisateur entraîne la suppression de toutes ses entrées dans `library_item`.
5. **Validation des notes** : Si une note est attribuée, elle doit être comprise entre 1 et 5.
6. **Statut par défaut** : Lors de l'ajout d'un livre, le statut par défaut est "A lire" (`TO_READ`).
7. **Mise à jour automatique** : Le champ `updatedAt` doit être automatiquement mis à jour à chaque modification (via trigger ou logique applicative).

## Conventions de nommage

- **Tables** : noms en minuscules avec underscore (snake_case) : `user`, `book`, `library_item`
- **Champs** : camelCase : `userId`, `createdAt`, `openLibraryId`
- **Types ENUM** : PascalCase : `ReadingStatus`
- **Clés étrangères** : nommées explicitement : `fk_user`, `fk_book`
- **Contraintes** : nommées explicitement : `unique_user_book`
