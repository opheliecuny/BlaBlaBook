# Liste des technologies utilisées et justifications

## Frontend

| Technologie     | Rôle            | Justification                                                                                  |
| --------------- | --------------- | ---------------------------------------------------------------------------------------------- |
| Next.js         | Framework React | Routing intégré (App Router), optimisé SEO (SSR), très utilisé en production, écosystème riche |
| TypeScript      | Langage         | Typage statique, détection d'erreurs à la compilation, meilleure maintenabilité en équipe      |
| Tailwind CSS v4 | Styles          | Développement rapide, responsive natif, classes utilitaires, pas de conflit de nommage CSS     |
| shadcn/ui       | Composants UI   | Composants modernes accessibles, intégration native avec Tailwind, personnalisables            |

---

## Backend

| Technologie | Rôle                   | Justification                                                                            |
| ----------- | ---------------------- | ---------------------------------------------------------------------------------------- |
| Node.js     | Environnement serveur  | JavaScript fullstack, large écosystème npm, cohérence avec le frontend                   |
| Express     | Framework API          | Minimaliste, structure claire pour une API REST, très documenté et maîtrisé en formation |
| Zod         | Validation des données | Validation et typage des entrées utilisateur côté serveur, sécurisation des inputs       |

---

## Base de données

| Technologie | Rôle             | Justification                                                                               |
| ----------- | ---------------- | ------------------------------------------------------------------------------------------- |
| PostgreSQL  | SGBD relationnel | Robuste, adapté aux relations entre utilisateurs/livres/statuts, très utilisé en entreprise |
| Prisma ORM  | Accès BDD        | Requêtes typées, migrations simples, protection automatique contre les injections SQL       |
| Supabase    | Hébergement BDD  | PostgreSQL managé, interface d'administration intégrée, connexion simple                    |

---

## Authentification et Sécurité

| Technologie | Rôle                   | Justification                                                            |
| ----------- | ---------------------- | ------------------------------------------------------------------------ |
| JWT         | Sessions               | Stateless, compatible API REST, pas de stockage côté serveur nécessaire  |
| argon2      | Hash des mots de passe | Standard de sécurité pour le hachage, résistant aux attaques brute-force |
| Zod         | Validation des schémas | Sécurise les données entrantes avant tout traitement                     |

---

## API externe

| Technologie      | Rôle                     | Justification                                                                     |
| ---------------- | ------------------------ | --------------------------------------------------------------------------------- |
| Open Library API | Données bibliographiques | Catalogue vaste et à jour, gratuite, évite de maintenir une base de livres propre |

## DevOps et Outillage

| Technologie | Rôle                        | Justification                                                                                                 |
| ----------- | --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Docker      | Conteneurisation            | Environnement de développement identique pour les 4 développeurs, évite les problèmes de configuration locale |
| Vercel      | Déploiement frontend        | Intégration native avec Next.js, déploiement automatique depuis GitHub                                        |
| Render      | Déploiement backend         | Simple pour héberger une API Node.js, tier gratuit disponible                                                 |
| GitHub      | Versionning & collaboration | Gestion des branches, Pull Requests, Kanban intégré pour le suivi de projet                                   |
| Postman     | Test des endpoints API      | Permet de tester et documenter les routes API pendant le développement                                        |
| VSCode      | Editeur                     | Editeur commun à toute l'équipe, extensions partagées pour une expérience cohérente                           |
