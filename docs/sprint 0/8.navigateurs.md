BlaBlaBook cible les navigateurs modernes dans leurs versions récentes (N et N-1). Les navigateurs anciens (Internet Explorer, etc.) ne sont pas supportés.

## Navigateurs supportés

| Navigateur      | Version minimale | Plateforme                     |
| --------------- | ---------------- | ------------------------------ |
| Google Chrome   | 120+             | Desktop & Mobile (Android)     |
| Mozilla Firefox | 120+             | Desktop                        |
| Microsoft Edge  | 120+             | Desktop                        |
| Safari          | 17+              | Desktop (macOS) & Mobile (iOS) |

### Remarques

- Safari / iOS mérite une attention particulière : c'est le navigateur par défaut d'Apple, il concentre donc l'essentiel du trafic mobile Apple. Certaines fonctionnalités CSS ou Web APIs peuvent se comporter différemment et nécessitent des tests spécifiques.
- Chrome Mobile (Android) et Safari Mobile (iOS) sont les deux navigateurs mobiles prioritaires, en cohérence avec l'approche mobile-first du projet.
- Les navigateurs non listés (Opera, Brave, etc.) peuvent fonctionner mais ne font pas l'objet de tests dédiés — ils partagent généralement le moteur Chromium avec Chrome.
- Internet Explorer n'est pas supporté.

---

## Stratégie de compatibilité

- Next.js et Tailwind CSS gèrent nativement le support des navigateurs modernes via leur configuration de compilation
- Les préfixes CSS éventuellement nécessaires sont gérés automatiquement par PostCSS / Autoprefixer
- Les tests manuels seront effectués sur Chrome et Safari en priorité (desktop + mobile)
