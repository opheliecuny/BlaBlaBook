# Analyse des risques

Sécuriser l'accès aux fonctionnalités de l'application :

- bibliothèque personnelle
- gestion des livres
- données utilisateur

---

## Méthode utilisée

L'application utilise :

JWT (JSON Web Token)

avec :

- argon2 pour les mots de passe
- middleware d'authentification

---

## 1. Hash des mots de passe

Les mots de passe ne sont jamais stockés en clair.

Ils sont hashés avec :

**argon2**

Exemple :

```js
const hashedPassword = await argon2.hash(password);
```

---

## 2. Protection SQL Injection

La base utilise :

**Prisma ORM**

Ce qui protège automatiquement contre les injections SQL.

Exemple sécurisé :

```typescript
prisma.user.findUnique({
 where: { email }
})
```

---

## 3. Validation des données

Toutes les entrées utilisateur sont validées avec :

**Zod**

Exemple :

```typescript
const schema = z.object({
 email: z.string().email(),
 password: z.string().min(8)
});
```

---

## 4. Protection XSS

Les bonnes pratiques appliquées :

- échapper les entrées utilisateur
- ne pas utiliser `dangerouslySetInnerHTML`
- utiliser React (qui protège déjà contre XSS)
- utilisation de Helmet

---

## 5. Protection des routes

Middleware :

**authMiddleware**

Exemple :

```typescript
export function authMiddleware(req, res, next) {

 const token = req.headers.authorization?.split(" ")[1];

 if(!token) {
   return res.status(401).json({ error: "Unauthorized" });
 }

 next();
}
```
