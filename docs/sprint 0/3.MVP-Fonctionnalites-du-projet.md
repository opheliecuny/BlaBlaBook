# Les fonctionnalités du projet

## Qu'est-ce que le MVP ?

Le **Minimum Viable Product (MVP)** est la version minimale du produit qui :

- fonctionne de bout en bout
- apporte une valeur utilisateur
- peut être démontrée

Toutes les fonctionnalités **non essentielles** seront exclues du MVP.

---

## Les fonctionnalités

## 1 — Authentification

L'utilisateur peut :

- créer un compte
- se connecter
- se déconnecter

Fonctionnalités :

- inscription
- connexion
- stockage sécurisé des mots de passe
- JWT pour les sessions

---

## 2 — Page d'accueil

Contenu :

- présentation du projet
- livres aléatoires
- lien vers recherche

---

## 3 — Recherche de livres

L'utilisateur peut :

- rechercher un livre

La recherche utilise :

Google Books API

Résultat :

- liste de livres
- titre
- auteur
- image
- description

---

## 4 — Page détail d'un livre

Informations :

- titre
- auteur
- description
- couverture
- date de publication
- éditeur

Source :

Google Books API

---

## 5 — Bibliothèque personnelle

Un utilisateur peut :

- ajouter un livre à sa bibliothèque
- supprimer un livre
- voir sa bibliothèque

Statuts possibles :

- à lire
- en cours
- lu

---

## Fonctionnalités hors MVP

Ces fonctionnalités pourront être ajoutées **si le temps le permet**.

### Interaction sociale

- avis
- notes
- commentaires

### Recommandations

- suggestions personnalisées

### Social

- bibliothèques publiques
- groupes de lecture

### Statistiques

- nombre de livres lus
- genres préférés

### Fonctionnalités avancées

- recherche filtrée
- chat entre utilisateurs
- scan ISBN

### Donner des droits supplémentaires à certains utilisateurs

- Pour approfondir l'etudes des notes et commentaires et donner son avis sur tel ou tel livre
