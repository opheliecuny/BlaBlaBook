## FRONTEND - Arborescence détaillée

```plaintext
frontend/
├── app/
│   ├── layout.tsx       # Layout global de l'application (Navbar, Footer)
│   ├── page.tsx         # Page d'accueil (route `/`)
│   ├── login/
│   │   └── page.tsx     # Page de connexion (route `/login`)
│   ├── register/
│   │   └── page.tsx     # Page d'inscription (route `/register`)
│   ├── search/
│   │   └── page.tsx     # Page de recherche (route `/search`)
│   ├── book/
│   │   └── [id]/
│   │       └── page.tsx # Page détaillée d'un livre (route `/book/:id`)
│   ├── library/
│   │   └── page.tsx     # Page de la bibliothèque (route `/library`)
│   ├── profile/
│   │   └── page.tsx     # Page de modification du profil (route `/profile`)
│   └── legal/
│       └── page.tsx     # Page mentions légales et CGU (route `/legal`)
│
├── components/
│   ├── Navbar.tsx       # Barre de navigation
│   ├── BookCard.tsx     # Carte d'affichage d'un livre
│   ├── BookList.tsx     # Liste de livres
│   └── LibraryItem.tsx  # Elément de bibliothèque
│
├── services/
│   ├── api.ts           # Configuration de base de l'API (fetch)
│   ├── authService.ts   # Services d'authentification (Inscription, Connexion, Déconnexion)
│   ├── userService.ts   # Services de gestion du profil utilisateur
│   ├── bookService.ts   # Services liés aux livres (Recherche et détail via Open Library API)
│   └── libraryService.ts # Services liés à la bibliothèque (CRUD bibliothèque personnelle)
│
├── contexts/
│   └── AuthContext.tsx  # Contexte d'authentification
│
├── hooks/
│   └── useAuth.ts       # Hook personnalisé pour accéder au contexte auth
│
└── types/
    ├── book.ts               # Types liés aux livres
    ├── user.ts               # Types liés aux utilisateurs
    └── library.ts            # Types liés à la bibliothèque (statuts, entrées)
```

## BACKEND - Arborescence détaillée

```plaintext
backend/
└── src/
    ├── controllers/
    │   ├── authController.ts     # Logique inscription / connexion
    │   ├── userController.ts     # Logique modification profil utilisateur
    │   ├── bookController.ts     # Recherche et détail de livres
    │   └── libraryController.ts  # CRUD bibliothèque utilisateur
    │
    ├── routes/
    │   ├── authRoutes.ts         # Routes /auth/*
    │   ├── userRoutes.ts         # Routes /user/*
    │   ├── bookRoutes.ts         # Routes /books/*
    │   └── libraryRoutes.ts      # Routes /library/*
    │
    ├── services/
    │   ├── authService.ts        # Hash mdp, génération JWT
    │   ├── bookService.ts        # Appels Open Library API
    │   └── libraryService.ts     # Requêtes Prisma bibliothèque
    │
    ├── middlewares/
    │   └── authMiddleware.ts     # Vérification JWT sur routes protégées
    │
    └── utils/
        └── validateSchema.ts     # Validation Zod des entrées
```

## Navigation utilisateur

```plaintext
Page d'accueil (/)
├── → /login          (connexion)
│       └── → /library    (accès bibliothèque après connexion)
│               └── → /profile    (modification du profil)
├── → /register       (création de compte)
│       └── → /library    (accès bibliothèque après inscription)
├── → /search         (recherche de livres)
│       └── → /book/:id   (fiche détaillée)
│               └── → /library    (ajout du livre à la bibliothèque)
│                           └── suppression d'un livre
└── → /legal          (mentions légales et CGU - accessible depuis le footer)
```
