# Présentation du projet - BlaBlaBook

## Vision

BlaBlaBook est une plateforme web permettant aux utilisateurs de :

- gérer leur bibliothèque personnelle
- découvrir de nouveaux livres
- consulter des informations détaillées sur les livres
- interagir avec une communauté de lecteurs

L’objectif principal est de mettre en pratique :

- le développement **fullstack**
- l’architecture **API REST**
- la gestion de projet **Agile**
- la collaboration avec **GitHub**

---

## Objectifs pédagogiques

Le projet doit permettre d’apprendre :

- conception d’architecture web moderne
- structuration d’un projet fullstack
- travail en équipe avec Git
- gestion de projet Agile avec Kanban
- déploiement d’une application web
