## FRONTEND

### Exemple d'arborescence détaillée

```plaintext
frontend/
├── app/
│   ├── layout.tsx       # Layout global de l'application
│   ├── page.tsx         # Page d'accueil (route `/`)
│   ├── login/
│   │   └── page.tsx     # Page de connexion (route `/login`)
│   ├── register/
│   │   └── page.tsx     # Page d'inscription (route `/register`)
│   ├── search/
│   │   └── page.tsx     # Page de recherche (route `/search`)
│   ├── book/
│   │   └── [id]/
│   │       └── page.tsx # Page détaillée d'un livre (route `/book/:id`)
│   └── library/
│       └── page.tsx     # Page de la bibliothèque (route `/library`)
│
├── components/
│   ├── Navbar.tsx       # Barre de navigation
│   ├── BookCard.tsx     # Carte d'affichage d'un livre
│   ├── BookList.tsx     # Liste de livres
│   └── LibraryItem.tsx  # Élément de bibliothèque
│
├── services/
│   ├── api.ts           # Configuration de base de l'API
│   ├── authService.ts   # Services d'authentification
│   ├── bookService.ts   # Services liés aux livres
│   └── libraryService.ts # Services liés à la bibliothèque
│
├── contexts/
│   └── AuthContext.tsx  # Contexte d'authentification
│
├── hooks/
│   └── useAuth.ts       # Hook personnalisé pour l'authentification
│
├── types/
│   ├── book.ts          # Types liés aux livres
│   ├── user.ts          # Types liés aux utilisateurs
│   └── library.ts       # Types liés à la bibliothèque
│
└── styles/              # (Optionnel) Fichiers CSS/SCSS globaux
```
