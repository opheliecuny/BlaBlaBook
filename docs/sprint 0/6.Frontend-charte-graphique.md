## Composants Clés (shadcn/ui)

### 1. Cartes (BookCard)

**Propriétés visuelles** :

- `rounded-xl` (12px) pour les coins.
- `shadow-sm` pour une ombre subtile.
- `border border-slate-100` (mode clair) / `border border-slate-800` (mode sombre).
- **Hover** : `transform hover:scale-[1.02] transition-transform` + bordure en `--color-accent`.

### Structure

```tsx
// BookCard.tsx
import { Card, CardContent, CardFooter } from "@/components/ui/card";
import Image from "next/image";

export function BookCard({ book }) {
  return (
    <Card className="w-64 hover\:shadow-md transition-shadow">
      <div className="relative h-80 w-full">
        <Image
          src={book.cover}
          fill
          className="object-cover rounded-t-xl"
          alt={book.title}
        />
      </div>
      <CardContent className="p-4">
        <h3 className="font-playfair text-lg font-semibold">{book.title}</h3>
        <p className="text-sm text-slate-600 dark\:text-slate-400">
          {book.author}
        </p>
      </CardContent>
      <CardFooter className="flex justify-between p-4">
        <Button variant="ghost" size="sm">Détails</Button>
        <Button variant="outline" size="sm">Ajouter</Button>
      </CardFooter>
    </Card>
  );
}
```

Pour un rendu **sobre et moderne**, je suggère de s'éloigner du "marron vieux livre" trop classique pour aller vers des teintes plus contemporaines.

## 1. Palette de Couleurs (Mode Clair/Sombre)

- **Primaire (Le Lien)** : `Indigo Profond` ou `Bleu Nuit`. Évoque le sérieux, la profondeur et la confiance.

- **Accent (L'Étincelle)** : `Vieux Rose` ou `Terracotta Doux`. Pour les boutons d'appel à l'action (CTA), apportant chaleur et humanité.

- **Neutres (Le Papier)** : `Gris Perle` très clair (#F9FAFB) pour le fond, et un `Anthracite` doux pour le texte (mieux que le noir pur pour la fatigue oculaire).

## 2. Typographie

- **Titres** : Une police **Serif** élégante (ex: Playfair Display ou Lora via Google Fonts). Cela rappelle l'imprimerie traditionnelle.

- **Corps de texte** : Une **Sans-Serif** moderne et lisible (ex: Inter ou Geist Sans, très populaire avec shadcn/ui).

## 3. Composants shadcn/ui clés

- **Cards** : Avec de légères ombres (`shadow-sm`) et des coins arrondis (`rounded-xl`) pour un aspect "objet" premium.

- **Empty States** : Utiliser des illustrations filaires (Lucide React) pour inciter l'utilisateur à ajouter son premier livre.

## Raffinement de la Charte Graphique

### Iconographie (Finesse & Abstraction)
Puisque vous préférez le trait fin, nous allons utiliser la bibliothèque Lucide React (standard avec shadcn/ui) avec une épaisseur de trait (stroke-width) de `1.5` ou `1.25` au lieu du standard `2`. Cela donne immédiatement un aspect plus "architectural" et moderne.

### Architecture d'Échange (Social)
- **Le Club de Lecture** : Ne le voyez pas comme un simple forum, mais comme un "Espace Bulle". Dans l'UI, cela se traduit par des avatars empilés (Facepile) sur les cartes de livres pour montrer qui lit quoi en temps réel.

- **Commentaires** : Un système de "Threads" imbriqués très sobre, utilisant des lignes verticales fines pour guider la lecture sans alourdir.

## Structure des Composants (Frontend)
Avec Next.js et shadcn/ui, voici comment organiser vos vues pour intégrer l'API Google Books :

### 1. La Carte de Livre (BookCard.tsx)
C'est l'élément central. Elle doit être épurée.

- **Image** : Utilisation de `next/image` avec un `aspect-ratio` de 2/3.
- **Survol (Hover)** : Une légère mise en avant avec une bordure subtile ou une ombre portée douce.
- **Indicateur Social** : Une petite pastille indiquant le nombre de discussions actives dans le club de lecture lié.

### 2. Le Feed de Discussion (DiscussionThread.tsx)
Pour les commentaires, privilégiez la clarté :

- Typographie `Inter` en taille `sm` (14px) pour les textes.
- Séparateurs horizontaux très légers (`border-slate-100`).
