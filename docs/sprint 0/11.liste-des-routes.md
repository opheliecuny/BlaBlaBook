# Liste des routes prévues

Les routes frontend sont indiquées dans le point [arborescence-application](8.arborescence-application.md).
Ce point se concentre donc sur les endpoints de l'API REST.

---

## Rappel routes frontend

| Route       | Page                       | Accès       |
| ----------- | -------------------------- | ----------- |
| `/`         | Page d'accueil             | Public      |
| `/login`    | Connexion                  | Public      |
| `/register` | Inscription                | Public      |
| `/search`   | Recherche de livres        | Public      |
| `/book/:id` | Fiche détaillée d'un livre | Public      |
| `/library`  | Bibliothèque personnelle   | Authentifié |
| `/profile`  | Modification du profil     | Authentifié |
| `/legal`    | Mentions légales et CGU    | Public      |

---

## Routes Backend - Endpoints API REST

### Authentification - `/auth`

| Méthode | Route            | Description                   | Auth requise |
| ------- | ---------------- | ----------------------------- | ------------ |
| `POST`  | `/auth/register` | Créer un compte               | Non          |
| `POST`  | `/auth/login`    | Se connecter, retourne un JWT | Non          |

---

### Livres - `/books`

| Méthode | Route                   | Description                                | Auth requise |
| ------- | ----------------------- | ------------------------------------------ | ------------ |
| `GET`   | /`books/search?q=...`   | Rechercher des livres via Open Library API | Non          |
| `GET`   | `/books/:openLibraryId` | Récupérer le détail d'un livre             | Non          |

---

### Utilisateur - `/user`

| Méthode | Route           | Description                         | Auth requise |
| ------- | --------------- | ----------------------------------- | ------------ |
| `PATCH` | `/user/profile` | Modifier les informations du profil | Oui          |

---

### Bibliothèque - `/library`

| Méthode  | Route          | Description                                         | Auth requise |
| -------- | -------------- | --------------------------------------------------- | ------------ |
| `GET`    | `/library`     | Récupérer la bibliothèque de l'utilisateur connecté | Oui          |
| `POST`   | `/library`     | Ajouter un livre à la bibliothèque                  | Oui          |
| `PATCH`  | `/library/:id` | Modifier le statut de lecture d'un livre            | Oui          |
| `DELETE` | `/library/:id` | Supprimer un livre de la bibliothèque               | Oui          |

---

## Détail du corps de requêtes

### POST `/auth/register`

```json
{
  "email": "user@mail.com",
  "password": "password123",
  "username": "reader42"
}
```

### POST `/auth/login`

```json
{
  "email": "user@mail.com",
  "password": "password123"
}
```

### POST `/library`

```json
{
  "openLibraryId": "OL123456W",
  "status": "TO_READ"
}
```

### PATCH `/library/:id`

```json
{
  "status": "READ",
  "rating": 4,
  "review": "Excellent livre, très captivant !"
}
```

**Note** : `rating` et `review` sont optionnels.

### PATCH `/user/profile`

```json
{
  "username": "nouveau_pseudo",
  "email": "nouvel@email.com",
  "password": "nouveau_mot_de_passe"
}
```

**Note** : Tous les champs sont optionnels. Seuls les champs fournis seront mis à jour.

### Statuts de lecture disponibles

| Valeur    | Signification |
| --------- | ------------- |
| `TO_READ` | A lire        |
| `READING` | En cours      |
| `READ`    | Lu            |
